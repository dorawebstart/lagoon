# Правила для Claude Code (Lagoon)

Повний план і порядок кроків — у [PLAN.md](PLAN.md). Працюй за ним крок за кроком.

## Спілкування
- Мова спілкування — українська.
- Коментарі в коді — **українською** по всьому проєкту (ідентифікатори англійською).

## Rust — пояснюй
Автор знає JS/PHP, але не Rust. Тому:
- до кожного нового Rust-файлу чи функції — коротке пояснення українською: що робить і які поняття Rust використано (ownership, borrowing, `Result`, `Option`, `?`, `async`, `trait`, макроси);
- простий, читабельний Rust без «розумних» трюків; коментуй неочевидні місця;
- після кожного кроку — 3–5 питань для самоперевірки.

## Workflow
- Маленькі кроки: зміна → перевірка (`cargo check`, `cargo clippy`, запуск) → коміт.
- `main` завжди збирається і працює.
- Кожен крок плану — окрема гілка: `feat/01-skeleton`, `feat/02-island-window`, …
- Коміти у форматі Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`.
- Наприкінці кроку — PR (`gh pr create`) з описом: що зроблено, як перевірити, що нового в Rust. Мерж — `gh pr merge --squash` після мого перегляду.
- Версія однакова в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.

## Безпека
- Жодних секретів у репозиторії: токен для hooks і API-ключі — тільки в локальних налаштуваннях або `.env`.
- HTTP-сервер для hooks слухає лише `127.0.0.1`.

## Стиль коду
- Rust: `cargo fmt`, без попереджень `cargo clippy`.
- Frontend: vanilla JS (ES-модулі) + CSS, без фреймворків; усі тексти UI — через `src/locales/uk.json` і `en.json`.
